# 轻墨原生版

从一句话开始，把想法留在自己的电脑上。

可以在原生排版正文中写作，也可以切换到 Markdown 源码继续编辑。阅读视图适合检查文章的结构与节奏。

## 今天想写什么

- 一个值得记录的发现
- 一段还没有整理好的思路
- 一份明天要做的计划

**重要的想法**，用粗体留下来。*还没成形的念头*，也可以先写下来。

> 写作不必从完美的第一句开始。

## 一点 Markdown

源码中的 `# 标题` 表示一级标题，`**粗体**` 表示粗体。复杂内容可以在源码模式中编辑，再检查阅读效果。

```
int main() {
    return 0;
}
```

## 保存你的文章

新建一篇文章，或打开已有的 `.md` 文件。按 Ctrl+S 保存；用“另存为”把示例保存成自己的文章。

这一份文档也是普通 Markdown 文件。
